# Mockup sources

The seven look-B screens published on the private canvas https://claude.ai/artifact/GcSURykGvjJGXujETaqa1m.

Each `.html` file is one artboard of that canvas in its authoring format. `/*SHARED*/` in a file's style block stands for the contents of `b.css`. Images are referenced by the canvas's own asset ids (`/_blob/…`), so the files show no pictures when opened outside it.

| File | Screen |
| --- | --- |
| `Start.html` | Front door |
| `Pitch.html` | Logline pitch |
| `Story.html` | Story plan |
| `Prep.html` | Prep |
| `Main.html` | Shots (grid) |
| `Canvas.html` | Shots on the canvas |
| `Viewer.html` | Viewer |
| `Cut.html` | Cut: Picture, Sound and Export, three artboards in one file |

`Cut.html` was drawn on 2026-11-24 for slice 7. It is not on the canvas yet and is not agreed: the plan says the operator agrees it before the stage is built.

They are reference pictures, not code to copy: the app is built in Svelte with the tokens in `../DESIGN.md`.

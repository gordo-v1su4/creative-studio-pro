FILE 02 — SHEET TYPES AND PANEL LAYOUTS
=======================================

HOUSE RULE #1 — THE HEADLESS FRONTAL  ****THE ONE THING THAT MAKES THIS OURS****
In every sheet, the FULL-BODY FRONTAL panel is framed from the collarbones down:
NO HEAD IN THAT PANEL. The face is owned by the close-up panel, which is where
the model spends its detail. The frontal panel exists to show costume, build and
proportion. Keep the full-person scale and vertical placement: omit the head
without zooming or shifting the body up. Empty background above the shoulders
is intentional. The collarbones do not have to meet the top edge. Exact wording
to output, every time:

  "PANEL CENTRE: front at full-person scale and original vertical placement.
   Omit the head above the collarbones without enlarging or moving the body.
   Leave plain background above the shoulders. Feet visible, arms relaxed,
   weight even."

Repeat it inside LOCKS as: "the frontal full-body panel has no head — cropped at
the collarbones; the close-up panel is the only panel showing the face."
[If the user ever says they want the head kept in the frontal panel, drop this
rule for that job only and frame it head-to-toe instead.]

TYPE A — HERO KEY ART PLATE (default when the user says "character sheet")
White seamless, low-key body, rim lights, one accent colour. For posters,
thumbnails, reveals, fighter-select art.
  3-panel layout: LEFT close-up head+shoulders / CENTRE full body frontal
  (HEADLESS per House Rule #1) / RIGHT full body from behind.
  4-panel layout (use when the user asks for more views, smoke or a glow):
  1 large close-up / 2 three-quarter body / 3 full body frontal (HEADLESS) /
  4 full body rear.

TYPE B — IDENTITY LOCK SHEET (offer it, always)
Flat mid-grey, soft near-shadowless light, everything evenly readable. Ugly on
purpose. This is the file the user feeds Seedance / Soul ID / Cast, because a
video model invents whatever the hero plate hides in shadow.
  3 panels: full front / full back / face close-up. House Rule #1 still applies
  to the frontal panel.

TYPE C — HERO CLOSE-UP (poster shot), single portrait panel, 135mm, frost/sweat
and pore detail carrying the realism.

ORDER OF WORK to recommend when asked: design brief -> batch the identity sheet
6-10 times -> pick on lighting first, face second -> lock it and name it ->
restyle the locked sheet into the hero plate in edit mode -> only then video.
FILE 03 — OUTPUT TEMPLATES (BLOCK ORDER IS FIXED)
=================================================
Always output in this order: SHEET, SUBJECT, COSTUME, SILHOUETTE, LIGHTING,
GRADE, CAMERA, REALISM, LOCKS. Labelled plain text, no JSON unless asked.

T1 — HERO PLATE, 3 PANELS
Create a photorealistic character key art plate: ONE character shown in three
panels side by side on a single canvas, separated by clean white gaps, no
borders, no text.
PANEL LEFT: tight close-up of the head and upper shoulders, filling the panel,
straight-on, face square to the camera, head level with no tilt, looking directly
into the lens; both eyes, both ears and the full jawline visible, even light on
both sides of the face.
PANEL CENTRE: front at full-person scale and original vertical placement.
Omit the head above the collarbones without enlarging or moving the body.
Leave plain background above the shoulders. Feet visible, arms relaxed,
weight even.
PANEL RIGHT: full body from behind, head to feet, same pose, showing the back of
the costume.
SUBJECT: [sex, age, build, height; face structure, skin, eyes, hair; wear]
COSTUME: [materials first, then the shapes they form, then the damage]
SILHOUETTE: [the one identifying shape]
LIGHTING: [File 01 block verbatim]
GRADE: [File 01 block, accent filled]
CAMERA: [File 01 block]
REALISM: [File 01 block]
LOCKS: the same identical person, costume, proportions and lighting in all three
panels; the frontal full-body panel has no head — cropped at the collarbones;
the close-up panel is the only panel showing the face; feet visible in both
full-body panels; no text, no logos, no watermark, no extra characters; not a 3D
render, not a video game screenshot, not a plastic or airbrushed look.

T2 — FOUR-PANEL WITH HAZE + PRACTICAL GLOW
Same as T1 with four panels and: pale grey-white seamless with thin drifting haze
and smoke behind the subject; PRACTICAL LIGHT: [glowing eyes / chest ember /
arcing energy] in [accent] [#HEX], lighting only the surfaces immediately around
it, never filling the scene.

T3 — HERO CLOSE-UP
Photorealistic cinematic close-up of [character], head to collarbones,
straight-on, face square to the camera, head level with no tilt, looking directly
into the lens. FACE: [age, structure, skin condition, eye colour], visible
pores, fine lines, individual eyebrow hairs, [frost/sweat/dust]. [Mask] of
[material] with [wear]. LIGHTING/GRADE per File 01. CAMERA: 135mm, shallow DOF,
focus on the near eye. LOCKS: one person, no text, no logo, not airbrushed.

T4 — IDENTITY LOCK SHEET
Character sheet of one [type], three panels side by side, plain mid-grey studio
backdrop, thin dark dividers. LEFT: full-body front, framed from the collarbones
down, no head in this panel, shoes in frame, standing straight, arms relaxed.
CENTRE: full-body back, head to toe, same pose, facing away. RIGHT: close-up of
face and shoulders, calm gaze. [SUBJECT] [OUTFIT, every layer with materials and
footwear] [identity-sheet lighting from File 01]
LOCKS: one identical person in all three views — same identity, outfit, hair,
proportions; frontal panel headless, cropped at the collarbones; feet visible in
both full-body panels; identical backdrop and light; sharp realistic photo.

T5a — IMAGE-FED, GPT IMAGE EDIT MODE
If a body reference is selected, omit all height, build and figure descriptions
from SUBJECT and the hand-off. Say "Match the body shape and proportions exactly
like image N." If sources show only a face, describe the body to create in detail;
any stated height is in centimetres. The selected body-reference rule takes
precedence over the generic SUBJECT placeholder in T1.
Using Image 1 as the identity and costume reference, create a three-panel plate
of the SAME person [panels per T1].
PRESERVE EXACTLY from Image 1: facial structure, skin tone and texture, eye shape
and colour, hairline and hair, body proportions, and every costume element —
materials, colours, hardware, damage and wear. Do not redesign, do not idealise,
do not clean up.
CHANGE ONLY the presentation: [File 01 lighting, grade, grain].
LOCKS: [as T1]

T5b — IMAGE-FED, SEEDREAM (ROLES NAMED)
Image 1 controls the character's identity: face, hair, proportions. Image 2
controls the costume: materials, colours, hardware, wear. Image 3 controls the
lighting and colour treatment only — match its light direction, contrast and
palette, and take nothing else from it. [then panels + File 01 blocks + 2K]

T6 — VARIATION ENGINE (batch of different characters, one look)
FIXED — identical every generation: [File 01 lighting, grade, camera, realism].
FREE — invent fresh each time: face, age, build, ethnicity, hair, exact costume
details and the accent colour.
CONSTRAINTS ON THE INVENTION: costume built from [materials], must include a mask
or face covering, one strong identifying silhouette shape, must not resemble any
existing game or film character.

FILE 14 — TWO-FIGHTER PLATES AND POSTERS
========================================

V1 — VS FACE-OFF PLATE (the most-used image in a fighting series)
Two characters, one frame, and two problems: two identities to hold, and two
accent colours competing. Solve both explicitly.

Create a photorealistic two-character face-off key art plate on a single canvas.
COMPOSITION: [CHARACTER A] on the left facing right, [CHARACTER B] on the right
facing left, both from the knees up, turned three-quarters toward each other,
heads level, a clear vertical gap of empty background between them at the centre
of the frame. Both faces fully visible. Neither overlaps the other.
[CHARACTER A]: [subject + costume + silhouette, condensed to four lines]
[CHARACTER B]: [same]
LIGHTING: high-key near-white seamless lit evenly, brightest in the gap between
them; both figures lit low-key several stops darker, each with a large soft key
from their own outer side and a narrow rim from behind, almost no fill,
catchlights in all four eyes; no shadow falling on the backdrop.
COLOUR SPLIT: [A's accent] [#HEX] appears only on the left figure, [B's accent]
[#HEX] only on the right; everything else desaturated near-monochrome; the two
accents never mix or bleed across the centre gap.
CAMERA: 100mm, chest height, straight on, both figures equally sharp.
LOCKS: exactly two characters, each identical to their own reference sheet, no
third figure, no merged costumes, no shared hardware, no text, no logos, not a
3D render.
[If the user has sheets for both, write the T5a image-fed version instead: Image
1 is character A's identity and costume, Image 2 is character B's — state that
neither may borrow from the other.]

V2 — FIGHT KEY FRAME (two characters mid-action, in a location)
Same two-identity discipline, but in an arena. Name the contact: which limb, on
what target, with what result. State who is on the left and which landmark each
one is near, so the geography matches the arena plate. Light with the location
block from File 08, not the studio block. One accent per fighter, plus the
location's own light.

P1 — POSTER / KEY ART WITH TEXT
Vertical 2:3 poster of [character], [framing], on [background treatment].
[subject + costume + silhouette + lighting + grade blocks]
TEXT: the words "[EXACT TEXT]" appear exactly once, [position: lower third /
across the bottom], in [typography: heavy condensed sans, wide letter-spacing,
uppercase], [colour]. No other text anywhere in the image.
COMPOSITION: keep the upper third clear for the title, subject centred, generous
negative space, nothing important within 8% of any edge.
LOCKS: one character, one text element, no logos, no watermark, no extra glyphs,
no garbled letters.
Keep titles to one to five words. Anything longer will garble.

P2 — FIGHTER SELECT / ROSTER TILE
Square or 4:5 tile of one character, waist up, centred, facing camera, on the
house background, with generous margin for a UI overlay. Same lighting and grade
blocks. No text. State that the framing must match across every tile in a set:
same crop height, same head position, same distance — this is what makes a
roster grid look designed rather than assembled.

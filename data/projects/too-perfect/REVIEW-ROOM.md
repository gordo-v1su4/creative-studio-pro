# Too Perfect: images in Review Room

The main images live in Review Room (https://review.v1su4.dev), project **Too Perfect** `ks75drxa63detat0ycy3d0mv9d8hgsrs`. The local copies stay on the Windows desktop under `data/projects/too-perfect/` and aren't in git.

**How to get a file:**
1. `GET /api/v1/versions/{versionId}/media`, with `Authorization: Bearer $REVIEW_ROOM_AGENT_API_KEY` (from BWS).
2. The response holds short-lived signed URLs (about 10 minutes). Download those without the bearer header, never store them, and ask again when they expire.

API contract: https://review.v1su4.dev/review-room-openapi.json

The Higgsfield CDN links in `HANDOFF.md` are a public fallback for the 11 main references.
